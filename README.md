# Hi, I'm Desi

SOC analyst working in managed detection and response, on my way to penetration testing.

I came to security from a different world: years in maritime hospitality and German-language customer service. What I took from it is staying calm when things break, explaining them clearly, and caring about the people affected. Now I apply that to incidents.

## What I do

- Investigate endpoint alerts and incidents end to end: triage, scoping, root cause, containment, reporting
- Hunt for persistence and lateral movement on Windows hosts with PowerShell and EDR telemetry
- Write incident reports for two audiences: technical teams and the people who have to act on them
- Configure and troubleshoot firewalls and VPNs (FortiGate, IPsec)
- Build small tools that make the next investigation faster

## Featured work

**[Incident case study: mitmproxy banking trojan and file encryption](https://github.com/dpetrova-sec/ir-case-mitm-banking-trojan)**
A real case, fully anonymised: a banking trojan built from legitimate open-source tools that injected JavaScript into every web page and watched 3-D Secure card payments for months, until a careless file encryptor gave it away. Includes the investigation path, a keystream-reuse weakness in the encryptor, MITRE mapping, IOCs, and a read-only PowerShell sweep script with bit-flag exit codes for RMM consoles.
